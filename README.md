# 🧮 Multi Calculator App

A simple, modern, and user-friendly Multi Calculator application designed to make everyday calculations easier. It brings multiple calculation tools together in one place with a clean interface and a smooth user experience.

## 📱 About the Project

Multi Calculator is an application that provides a convenient way to perform different types of calculations without switching between multiple apps. Its simple design makes calculations quick and easy for everyday use.

## ✨ Features

- **Multiple Calculations:** Access different calculation tools in one application.
- **User-Friendly Interface:** Clean and easy-to-use design.
- **Fast Calculations:** Get results quickly and accurately.
- **Modern Design:** Attractive layout with a simple user experience.
- **Mobile-Friendly:** Designed for convenient use on mobile devices.
- **Easy Navigation:** Switch between calculation tools easily.

## 🛠️ Technologies Used

- Flutter
- Dart

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/savaliyabhargav20/Multi_Calculator.git
```

**2. Navigate to the project directory**

```bash
cd Multi_Calculator
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
